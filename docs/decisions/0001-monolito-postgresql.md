# 0001 — Monólito modular com PostgreSQL

Data: 2026-09-22  
Status: aceita

Manter backend, páginas e API no mesmo processo FastAPI, com PostgreSQL como armazenamento operacional único. A decisão reduz componentes na máquina simples e segue a especificação. Integrações externas serão adaptadores opcionais; a aplicação inicia sem IA e sem n8n.
