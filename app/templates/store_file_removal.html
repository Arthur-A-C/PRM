Digitalização / Arquivos de produtos

Remoção de arquivos de produtos

Desvincula imagens e documentos de produtos WooCommerce existentes, localizados por SKU exato. Os arquivos permanecem na biblioteca de mídia; nome, descrições, categorias, atributos, preço, estoque, SKU e status nunca são alterados. Dry Run e aprovação são obrigatórios.

{{ ui.icon('package') }}Cadastro via API

1. Produtos e modo de remoção

Cole os SKUs (um por linha, ou separados por vírgula/ponto e vírgula) e/ou importe CSV/XLSX com coluna SKU. Zeros à esquerda são preservados; SKUs repetidos são unificados.

Modo de remoção

{{ ui.icon('info') }}Requer o worker scripts/store_removal_worker.py. A prévia só lê a loja. Nas lojas atuais, a execução exige liberação de uso único por loja, SKU, modo e hash do Dry Run.
